الخصوصية وحقوق الملكية - بورتات الألعاب

آخر تحديث: 2 نوفمبر 2026

ما يفعله التطبيق

يعرض أخبارًا وروابط لمشاريع المعجبين لنقل الألعاب إلى أندرويد المنشورة علنًا على GitHub. هو مجاني بلا إعلانات ولا حسابات، ولا يستضيف ولا يوزّع أي لعبة أو ملف لعبة أو APK، بل يفتح صفحة المشروع على GitHub فقط.

البيانات

لا نجمع بيانات شخصية ولا نتتبعك. يحفظ التطبيق على جهازك فقط اللغة والمشاريع التي تتابعها وإعدادات الإشعارات وآخر بيانات محمّلة.

الأطراف الثالثة

  • تُجلب بيانات المشاريع من واجهة GitHub العامة بواسطة سكربت يعمل على GitHub، وتُستضاف صفحات التطبيق على GitHub Pages، وقد يسجّل GitHub عنوان IP وفق سياسته.
  • الضغط على «المصدر» يفتح GitHub الذي تحكمه سياسته.

الإشعارات

اختيارية بإذنك، وتُنشأ على جهازك فقط عند صدور مشروع جديد أو إصدار جديد لمشروع.

حقوق الملكية

  • أسماء الألعاب والشعارات ملك لأصحابها، والتطبيق مستقل وغير تابع لأي ناشر أو متجر.
  • تُعرض المشاريع كما يصفها مطوروها، ولا نتحقق من قانونيتها. يلزمك امتلاك نسخة قانونية من اللعبة، وأنت المسؤول عما تنزّله.
  • نستبعد آليًا المشاريع التي تبدو للقرصنة أو الإعلانات أو المواقع المشبوهة.
  • لصاحب الحق: إن كنت تملك حقوق عمل وترى أن إدراج مشروع معيّن مشكلة، راسلنا على البريد أدناه مع رابط المشروع وإثبات الملكية، وسنزيله من القائمة سريعًا. وللإبلاغ عن المحتوى نفسه استخدم آلية GitHub للإبلاغ.

Privacy & Rights - Game Ports

Last updated: November 2, 2026

What the app does

It shows news and links about fan-made Android game ports that are publicly published on GitHub. It is free, with no ads or accounts, and it does not host or distribute any game, game file or APK; it only opens the project's GitHub page.

Data

We collect no personal data and do not track you. The app stores on your device only your language, the projects you follow, notification settings and the last loaded data.

Third parties

  • Project data is fetched from the public GitHub API by a script running on GitHub, and the app is hosted on GitHub Pages, which may log your IP address under its policy.
  • Tapping "Source" opens GitHub, governed by its own policy.

Notifications

Optional and permission-based; created on your device only when a new project or a new release of a project appears.

Intellectual property

  • Game names and logos belong to their owners. The app is independent and not affiliated with any publisher or store.
  • Projects are shown as described by their developers and we do not verify their legality. You need your own legal copy of the game and are responsible for what you download.
  • Projects that look like piracy, ads or suspicious sites are excluded automatically.
  • Rights holders: if you own rights to a work and believe listing a specific project is a problem, email us below with the project link and proof of ownership and we will remove it from the list promptly. To report the content itself, use GitHub's reporting process.
